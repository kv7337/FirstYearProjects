Rasadnik Prud — Full-Stack E-commerce Web Application

Project type: Final-year technical project for a family business

Technologies: React, JavaScript, PHP, MySQL, Bootstrap, Axios

Developed a responsive web application for a family plant nursery to make browsing and ordering plants easier. The application connects a React frontend with a PHP REST API and a MySQL database. It includes an online shop and an administrative panel.

Key features:

  • Plant catalog with product images, details, and prices.
  • Shopping cart, checkout, and order history.
  • User registration, login, and profile management.
  • Wishlist for saving favorite plants.
  • Admin panel for managing plants, orders, and business offers.
  • CSV export for saved offers.

My role: Full-stack development, database integration, user authentication, and implementation of customer-facing and administrative features.

RATELT — Survey Web Application

Project type: Final-year technical project

Technologies: React, Vite, PHP, MySQL, JavaScript, CSS, Bootstrap

Developed a full-stack web application that allows users to register, log in, complete surveys, earn points, and track their progress. The application connects a React frontend with a PHP backend and a MySQL database.

Key features:

  • User registration, login, and profile management.
  • Survey completion and saved completion status.
  • User dashboard displaying points and completed surveys.
  • Point redemption functionality.
  • Database integration for user and survey data.

My role: Front-end and back-end development, database integration, implementation of application features, and manual testing.

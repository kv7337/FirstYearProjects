Internet and Web Terminology

Internet & Networking

ARPANET (Advanced Research Projects Agency Network)
One of the first computer networks, developed in the United States in the late 1960s.
Example: ARPANET connected research institutions and helped establish the foundations of the Internet.
Related term: Internet
DNS (Domain Name System)
A system that translates domain names into IP addresses.
Example: DNS helps a browser find the server for a website such as example.com.
Related term: IP address
Further reading: MDN Web Docs, n.d.
Internet
A worldwide system of connected networks that exchange data using shared communication rules.
Example: Your phone uses the Internet when it connects to an online game or website.
Related term: TCP/IP
IP Address (Internet Protocol Address)
A numerical address used to identify a device on a network.
Example: A computer uses an IP address to communicate with a web server.
Related term: DNS
Packet Switching
A method of sending data by dividing it into smaller pieces called packets.
Example: When a file is sent over the Internet, it can travel as multiple packets.
Related term: TCP/IP
Protocol
A set of rules that devices follow to exchange information in a predictable way.
Example: A browser and server use HTTP rules to exchange web pages.
Related term: HTTP
TCP/IP (Transmission Control Protocol / Internet Protocol)
A group of communication protocols that allows devices and networks to exchange data.
Example: TCP/IP enables a laptop to communicate with servers around the world.
Related term: Internet

The Web

Browser (Web Browser)
A software application used to access and display websites.
Example: Google Chrome, Mozilla Firefox and Microsoft Edge are web browsers.
Related term: client
Client
A device or program that requests a service or information from another computer.
Example: A web browser acts as a client when it requests a page from a web server.
Related term: web server
CSS (Cascading Style Sheets)
A style sheet language used to control the appearance and layout of web pages.
Example: CSS changes the colors, fonts, spacing and layout of a website.
Related term: HTML
Further reading: MDN Web Docs, n.d.
HTML (HyperText Markup Language)
The standard markup language used to structure content on web pages.
Example: HTML elements create headings, paragraphs, images and links.
Related term: CSS
Further reading: MDN Web Docs, n.d.
Hyperlink
A clickable connection that takes users to another page, document or resource.
Example: Clicking a link in an article can open another website.
Related term: hypertext
Hypertext
Text that contains links to other information or documents.
Example: A web article with links to related pages uses hypertext.
Related term: hyperlink
Multimedia
Content that combines formats such as text, images, sound, animation or video.
Example: An online lesson may contain a video, diagrams and written explanations.
Related term: HTML
URL (Uniform Resource Locator)
The address used to locate a resource on the Web.
Example: https://www.example.com identifies a web resource.
Related term: browser
Web Server
A computer or software system that stores, processes and delivers web content to browsers.
Example: A web server sends an HTML page when a user opens a website.
Related term: client
WWW (World Wide Web)
A system of linked web pages and resources that people access through the Internet.
Example: Users browse the Web to read articles, watch videos and visit websites.
Related term: Internet

Protocols & Remote Access

HTTP (Hypertext Transfer Protocol)
A protocol used by browsers and web servers to exchange web resources.
Example: A browser uses HTTP to request a web page from a server.
Related term: HTTPS
Further reading: Fielding et al., 2022
HTTPS (Hypertext Transfer Protocol Secure)
A secure version of HTTP that uses encryption to protect data exchanged between a browser and a server.
Example: Online shopping websites use HTTPS to protect information during communication.
Related term: HTTP
Further reading: MDN Web Docs, n.d.
SFTP (SSH File Transfer Protocol)
A protocol that transfers and manages files through a secure SSH connection.
Example: A website administrator can use SFTP to upload files to a server.
Related term: SSH
Further reading: OpenBSD, n.d.
SSH (Secure Shell)
A protocol that allows users to securely access and manage another computer remotely.
Example: A developer can use SSH to connect to a remote server.
Related term: telnet
Further reading: Ylonen & Lonvick, 2006
Telnet
A network protocol that allows remote access to another computer, but does not encrypt the communication.
Example: Telnet was used to access remote computers before more secure alternatives such as SSH became common.
Related term: SSH

Interaction

CLI (Command-Line Interface)
A user interface where people interact with a computer by typing text commands.
Example: Developers use a terminal to run commands and manage files.
Related term: GUI
GUI (Graphical User Interface)
A user interface that allows people to interact with a computer through visual elements such as windows, icons and buttons.
Example: A desktop operating system usually provides a GUI.
Related term: CLI
HCI (Human–Computer Interaction)
The study and design of how people use and interact with computers and digital systems.
Example: Testing whether a website menu is easy to understand is part of HCI.
Related term: GUI
Further reading: Interaction Design Foundation, n.d.

Important Comparisons

Some Internet and Web terms are related, but they do not have the same meaning or purpose. The following table explains four important differences.

Comparison First Term Second Term Main Difference
Internet vs. Web Internet World Wide Web The Internet is a global network of connected devices. The Web is a system of linked resources that uses the Internet.
HTTP vs. HTTPS HTTP HTTPS HTTPS uses encryption to protect communication, while HTTP does not.
Telnet vs. SSH Telnet SSH Telnet sends data without encryption, while SSH provides secure communication.
CLI vs. GUI CLI GUI CLI uses typed commands, while GUI uses visual elements such as icons and windows.
